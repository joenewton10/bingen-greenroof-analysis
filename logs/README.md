# Pipeline Logs

This directory contains execution logs and diagnostic output from pipeline runs.

## Log Files

- `pipeline_log.txt` - Main pipeline execution log
- `pipeline_benchmark_*.txt` - Performance benchmarking data
- `ingest_log.txt` - Data ingestion stage logs
- `parkplatz_log.txt` - Parking lot specific logs
- `*.json` - Structured benchmark/status data

These files are generated during pipeline execution and are not version-controlled.
